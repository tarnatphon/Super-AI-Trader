# Super-AI-Trader

The best open AI trader — a multi-agent, AI-powered trading system.

## Research

Before building, we surveyed the top AI trading platforms, open-source AI agent
frameworks, YouTube creators, and practitioner communities (Reddit, Discord, X).

👉 **Read the full research report:** [`docs/RESEARCH-top-ai-traders-2026.md`](docs/RESEARCH-top-ai-traders-2026.md)

Highlights:
- **Top commercial platforms:** Trade Ideas (Holly AI), TrendSpider, 3Commas,
  Cryptohopper, Pionex, Coinrule, Tickeron, Composer, Capitalise.ai, AlgosOne.
- **Top open-source AI frameworks:** TradingAgents (~80K⭐, multi-agent trading firm),
  ai-hedge-fund (~50K⭐, investor-persona agents), FinRL (reinforcement learning),
  Freqtrade/FreqAI (execution + ML).
- **Top creators:** Moon Dev (RBI agents), Part Time Larry, Kevin Davey (Strategy
  Factory), algovibes, QuantProgram.
- **Core design principle:** LLM agents research/decide, but a hard, deterministic
  risk layer vetoes and a battle-tested engine executes.
